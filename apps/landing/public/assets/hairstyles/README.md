# Визуалы для страницы «Виртуальная примерка причёсок»

Положите сюда четыре изображения вертикального формата (рекомендуется `600×800`).

Для каждого слота приоритет формата такой: сначала `.webp`, затем `.png` или `.jpg`.

- `hairstyle-preview-1.webp` / `.png` / `.jpg`
- `hairstyle-preview-2.webp` / `.png` / `.jpg`
- `hairstyle-preview-3.webp` / `.png` / `.jpg`
- `hairstyle-preview-4.webp` / `.png` / `.jpg`

Они используются только на `/pricheski`. Для лучшей загрузки добавляйте `.webp`; если webp нет, лендинг возьмёт найденный `.png` или `.jpg`.
