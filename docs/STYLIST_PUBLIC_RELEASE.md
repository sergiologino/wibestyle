# Общий доступ к стилисту

AI-стилист и добавление причёски/цвета волос к результату примерки одежды доступны всем авторизованным пользователям. Вступление в фокус-группу больше не требуется.

- Общий флаг `wibestyle.features.flags.stylist` сохраняется и по умолчанию включён.
- Прежняя настройка `stylist-focus-group-only`, включая старую переменную `WIBESTYLE_STYLIST_FOCUS_GROUP_ONLY`, больше не ограничивает доступ.
- Поля фокус-группы в API и базе сохранены для совместимости. `stylistFocusGroupOnly` возвращается как `false`, а `stylistAvailable` зависит только от общего флага стилиста.
- Авторизация, доступ только к собственным сессиям и учёт баланса примерок сохраняются.

Для выпуска сначала обновить API, затем web-app и admin. Уже установленное мобильное приложение получает общий доступ при обновлении профиля из API; новая сборка мобильного приложения также убирает старые надписи о фокус-группе. Миграция пользователей или ручное включение доступа в админке не нужны.
